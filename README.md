## Cara Menjalankan Program

1. Buka folder proyek menggunakan Visual Studio Code.
2. Buka terminal.
3. Pastikan terminal berada di folder proyek.
4. Jalankan file menggunakan Node.js.

Contoh:

```bash
node 01-antrean-siswa.js
```

Ganti nama file sesuai latihan yang ingin dijalankan.
